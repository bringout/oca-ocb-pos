# Point of Sale Discounts



This module allows the cashier to quickly give percentage-based
discount to a customer.



## Installation

```bash
pip install odoo-bringout-oca-ocb-pos_discount
```

## Dependencies

- point_of_sale

## Source

- Repository: https://github.com/OCA/OCB
